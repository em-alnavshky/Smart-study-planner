# نظام إدارة وتصنيف المهام الدراسية الذكي 📚

برنامج تفاعلي مكتوب بلغة بايثون (Python) مصمم خصيصاً لمساعدة الطلاب على تنظيم واجباتهم واختباراتهم الدراسية.

## ✨ مميزات البرنامج:
- إضافة مهام دراسية غير محدودة.
- خوارزمية ذكية لتصنيف أولويات المهام تلقائياً (عالية جداً 🔴، متوسطة 🟡، منخفضة 🟢).
- استعراض قائمة المهام كاملة بشكل منظم لتسهيل تتبع الإنجاز اليومي.
